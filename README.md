# Zomato-Analytics

📌 Project Overview

This project analyzes Zomato restaurant data to understand restaurant ratings, pricing, cuisines, locations, and customer preferences. The analysis was performed using **Excel** for data cleaning and analysis and **Tableau** for interactive data visualization.

🎯 Objectives

* Analyze restaurant ratings and customer preferences
* Identify popular cuisines and restaurant categories
* Understand pricing trends across restaurants
* Analyze restaurant distribution by location
* Identify patterns and trends in the restaurant industry

🛠️ Tools Used

* **Microsoft Excel** – Data cleaning, transformation, and analysis
* **Tableau** – Interactive dashboards and data visualization

📊 Key Analysis

* Restaurant ratings analysis
* Average cost analysis
* Cuisine-wise restaurant analysis
* Location-wise restaurant distribution
* Rating and pricing trends
* Restaurant performance comparison

📈 Dashboard

The Tableau dashboard provides interactive visualizations to explore restaurant performance, ratings, pricing, cuisines, and locations.

💡 Key Insights

The analysis helps identify patterns in restaurant ratings, pricing, cuisine preferences, and location-wise restaurant availability.

📂 Project Files

* `Zomato_Analytics.xlsx` – Dataset and Excel analysis
* `Zomato_Dashboard.twbx` – Tableau dashboard
